# 유튜브 레시피 카드 정리

유튜브 요리 영상 → 주방에서 바로 쓸 수 있는 레시피 카드로 변환한다.

## 입력이 무엇인지부터 판단한다

| 입력 | 처리 |
|---|---|
| `docs/recipes/자막/*.txt` 파일 | 그대로 읽어서 카드 생성 (가장 흔한 경로) |
| 사용자가 붙여넣은 자막 텍스트 | 그대로 카드 생성 |
| 유튜브 링크만 | 자막을 못 가져오는 환경이면 **추측하지 말고** `recipe.bat` 실행을 안내한다 |
| 캡처 이미지 | 이미지에서 재료·분량·순서를 읽어 카드 생성 |

여러 파일을 한꺼번에 받으면 **영상 1개 = 카드 1장**으로 각각 만든다.

## 카드 형식 (이 순서를 고정한다)

```markdown
# {요리 이름}

> {한 줄 요약 — 어떤 맛/누구용인지}

| 항목 | 값 |
|---|---|
| 출처 | {채널명} — [{영상 제목}]({링크}) |
| 조리 시간 | {분} |
| 분량 | {인분} |
| 난이도 | 하 / 중 / 상 |
| 필요 장비 | {팬, 전자레인지 등} |

## 재료

| 재료 | 분량 | 비고 |
|---|---|---|
| … | … | 대체 가능 재료·생략 가능 여부 |

## 조리 순서

1. **{동작}** — {상세}. `(영상 0:42)`
2. …

## 핵심 포인트

- 맛이 갈리는 결정적 지점 2~4개

## 실패 포인트 ⚠️

- 이렇게 하면 망한다 2~3개

## 응용

- 재료 바꾸기 / 양 늘리기 / 매운맛 조절
```

## 규칙

1. **자막에 없는 분량을 지어내지 않는다.** 영상에서 "적당히"라고 하면 `적당히 (약 ○○g 추정)`처럼 추정임을 표시한다.
2. **타임스탬프를 살린다.** 자막에 시간 정보가 있으면 각 단계 끝에 `(영상 m:ss)`을 붙인다. 나중에 영상에서 그 장면을 바로 찾을 수 있어야 한다.
3. **말투를 지운다.** "자 이제 여러분" 같은 진행 멘트는 버리고 동작만 남긴다.
4. **순서를 재구성한다.** 영상은 왔다갔다 하지만 카드는 실제 조리 순서대로 정렬한다.
5. **분량은 표로.** 줄글에 섞지 않는다. 주방에서 훑어보는 용도다.
6. 자막이 깨졌거나 내용이 부족하면 억지로 채우지 말고 **무엇이 빠졌는지 명시**한다.

## 이 저장소(PLAYON)에서 쓸 때

PC방 메뉴로 쓸 레시피면 카드 끝에 다음 섹션을 추가한다.

```markdown
## 피시방 메뉴화

| 항목 | 값 |
|---|---|
| 예상 원가 | ○○원 |
| 권장 판매가 | ○○원 (마진율 ○○%) |
| 피크타임 조리 가능 | 가능 / 어려움 (조리 ○분) |
| PLAYON 상품 등록 | 카테고리 `먹거리` / 상품명 `○○` / 가격 `○○` |
```

- 원가율 30% 이하가 목표. 넘으면 분량 조정이나 판매가 인상을 함께 제안한다.
- 조리 8분이 넘으면 피크타임 판매 제한을 권고한다.
- 기존 조리 표준서 `docs/피시방-메뉴-레시피.md`와 겹치는 메뉴면, 새 카드를 만들되 **차이점을 명시**한다.

## 저장 위치

- 카드: `docs/recipes/{메뉴이름}.md`
- 목록: 카드를 추가하면 `docs/recipes/README.md`의 목록 표에 한 줄 추가한다.
