# 좌석 PC 클라이언트 에이전트 (2단계 설계)

각 좌석 PC에서 백그라운드로 도는 프로그램. 서버(카운터)와 통신하며 아래를 담당합니다.

## 역할
- **로그인/로그아웃**: 회원/게스트 착석 처리, 남은시간 표시
- **자동 잠금화면**: 시간 종료·미착석 시 화면 잠금(요금 안내)
- **게임 감지 → 사용량 보고**: 실행 중인 게임을 감지해 서버로 전송
- **원격 제어 수신**: 카운터에서 잠금/해제/공지

## 게임 감지 방식 (유료게임 연동 ①)
게토의 `wmtgn.ini`와 동일한 개념:
1. 현재 실행 중인 프로세스 목록을 주기적으로 확인
2. 서버의 `game_defs`(실행파일명 규칙)와 대조해 게임 식별
3. 감지 결과를 서버에 보고 → `game_usage`에 사용시간 누적

### 보고 API (이미 서버에 구현됨)
```
POST /api/agent/game
{ "seat_no": 3, "proc_name": "LeagueClient.exe" }
```
- 서버가 `game_defs`에서 매칭 → 사용 시작/종료를 자동 기록
- `proc_name` 대신 `game_code`로 직접 지정도 가능
- 감지된 게임이 없으면(게임 종료) 진행 중 사용 로그를 마감

## 유료게임 "정산"은 별도 (4단계) ⚠️
위 감지·측정까지는 이 프로젝트로 가능하지만, **넥슨/블리자드/RIOT 등에 실제 사용량을
보고하고 요금을 정산**하려면 각 게임사(또는 게임트리 등 정량제 통합 대행사)와의
**정식 제휴·API 계약**이 필요합니다. 인증된 PC방 관리프로그램만 접속할 수 있습니다.

## 구현 기술 후보
- Windows 네이티브 기능(프로세스 감시·화면 잠금)이 필요하므로 **C#/.NET(WPF)** 권장
- 프로토타입은 Node.js + PowerShell(`Get-Process`)로도 가능

## 감지 테스트 (에이전트 없이 수동)
서버 실행 후, 3번 좌석에서 롤이 켜졌다고 가정하고 보고를 흉내낼 수 있습니다:
```bash
curl -X POST http://localhost:8080/api/agent/game \
  -H "Content-Type: application/json" \
  -d "{\"seat_no\":3,\"proc_name\":\"LeagueClient.exe\"}"
```
카운터 대시보드의 3번 좌석에 게임명이 표시됩니다.
