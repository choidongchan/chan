# PLAYON — PC방 관리 프로그램

**PLAYON**은 좌석 관리 · 시간 과금 · 회원 관리 · 매출 집계 · 유료게임 사용시간 측정을
목표로 하는 PC방 관리 프로그램입니다. 단계적으로 만들어 갑니다.

> ⚠️ 이 프로젝트는 개발 초기(1단계)입니다. 실매장 도입 전에 반드시 검증/백업 절차를 거치세요.

## 전체 구성 (목표 아키텍처)

```
 ┌───────────────┐        ┌──────────────────────┐
 │  좌석 PC 클라이언트  │◀──────▶│      서버 (이 저장소)      │
 │  - 로그인/시간차감     │  WS/HTTP │  - DB (회원·좌석·세션·매출) │
 │  - 자동 잠금화면      │        │  - 과금 엔진             │
 │  - 게임 감지/보고     │        │  - REST API + 실시간(WS)  │
 └───────────────┘        └──────────┬───────────┘
                                       │
                          ┌────────────┴────────────┐
                          │   카운터 대시보드 (웹)       │
                          │  좌석현황·정산·회원·매출     │
                          └─────────────────────────┘
```

## 구현된 기능

- **좌석**: 배치도(드래그 편집·구역 라벨), 좌석 상세(충전·이동·판매·정산), 예약(초록석), 실시간 시계, 구역별 요금 자동적용, 전체 공지
- **고객/매출**: 회원관리(상세·블랙리스트), 이용내역, 상품관리(재고), 상품 버튼판매, 주문내역, 매출(일/월/연·7일 추이 그래프·CSV), 유료게임 리포트
- **운영**: 근무자·출퇴근·현금 시재·시스템 로그·키오스크 관제·요금제·쿠폰·매장설정
- **좌석 PC**: 회원 로그인·남은시간·자동잠금·공지 배너
- **배포**: dev.bat(저장 시 자동 커밋/푸시) + Render 자동 배포

## 개발 로드맵

- **1단계 (지금) — 서버 + 카운터 대시보드**  ✅ 진행 중
  - DB 스키마(좌석·회원·세션·요금제·매출·게임사용)
  - 좌석 현황 대시보드(실시간), 게스트/회원 착석·종료, 시간 과금, 매출 집계
- **2단계 — 좌석 PC 클라이언트 에이전트** (Windows)
  - 로그인/로그아웃, 남은시간 표시, 시간 종료 시 자동 잠금
  - 실행 게임 감지 → 서버로 사용량 보고 (`agent/` 참고)
- **3단계 — 회원/요금제 고도화 + 결제**
  - 선불·정액·쿠폰, 영수증, (카드 결제는 PG 인증 필요)
- **4단계 — 유료게임 정산 연동** ⚠️ 제휴/인증 필요
  - 게임 감지·시간 측정은 1~2단계에서 구현 가능
  - **실제 게임사 정산**은 각 게임사/정량제 대행사와의 계약이 있어야 함 (코드만으로 불가)
- **5단계 — 사장님 모바일 앱 / 원격 모니터링**

## 실행 방법 (1단계)

전제: [Node.js](https://nodejs.org) 20 이상, [Git](https://git-scm.com).

**가장 쉬운 방법 (Windows):** `chan` 폴더의 **`start.bat` 더블클릭**
→ 최신 버전 자동 업데이트 + 서버 실행이 한 번에 됩니다.

수동 실행:
```bash
git pull             # 최신 버전 받기
npm start            # 서버 실행 → http://localhost:8080
```

- **카운터 대시보드**: `http://localhost:8080` (직원 로그인 — 최초 `admin` / `admin1234`)
- **좌석 PC 화면(키오스크)**: `http://localhost:8080/seat.html?seat=3` (3번 좌석)
  - 회원 아이디로 로그인 → 남은시간 표시 → 시간 종료 시 자동 잠금
- **좌석 PC 에이전트**(게임 감지): `node agent/agent.mjs --seat 3 --server http://<서버IP>:8080`

처음 실행 시 예시 좌석/요금제/관리자 계정이 자동 생성됩니다(seed).

## 개발 → 배포 흐름 (Windows, 더블클릭)

**가장 편한 방법 — `dev.bat` 더블클릭 (저장하면 자동 배포):**
1. `dev.bat` 더블클릭 → 로컬 미리보기 서버 + 자동배포 감시 시작
2. VS Code로 코드 수정하고 **저장(Ctrl+S)만** 하면 →
   자동으로 git에 올라가고 → (Render 연결 시) 홈페이지에 자동 반영
3. push 버튼도, 명령어도 필요 없음

수동 방법: `start.bat`(실행) / `push.bat`(직접 올리기)

> 최초 1회만: ① 첫 실행 때 GitHub 로그인 ② Render 연결(`DEPLOY.md`). 이후 완전 자동.

```
agent/       좌석 PC 클라이언트 설계 문서 (2단계)
db/          DB 스키마
```
