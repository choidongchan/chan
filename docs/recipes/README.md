# 유튜브 레시피 정리 폴더

유튜브 요리 영상을 **레시피 카드**로 바꿔서 모아두는 곳입니다.
영상을 하나하나 보면서 받아적을 필요 없이, 주소만 넣으면 됩니다.

---

## 쓰는 법 (3단계)

### 1단계 — `recipe.bat` 더블클릭

`chan` 폴더의 **`recipe.bat`** 을 더블클릭하고, 영상 주소를 붙여넣습니다.

- **영상 하나**: 그 영상 주소를 넣습니다
- **채널 통째로**: 채널 주소(`https://www.youtube.com/@채널이름/videos`)를 넣고, 최근 몇 개까지 받을지 정합니다
- **여러 개 한꺼번에**: `docs/recipes/urls.txt` 에 주소를 한 줄에 하나씩 적어두고 `[2]`번을 고릅니다

자막이 `docs/recipes/자막` 폴더에 텍스트 파일로 저장됩니다.
한 번 받은 영상은 기록에 남아서 **다음에 다시 돌려도 새 영상만** 받습니다.

### 2단계 — `push.bat` 더블클릭

받은 자막을 올립니다. (변경 내용은 아무거나 적어도 됩니다. 예: `자막 추가`)

### 3단계 — "레시피 카드로 정리해줘" 라고 말하기

Claude에게 이렇게만 말하면 됩니다.

> 자막 올렸어. `docs/recipes/자막` 에 있는 거 레시피 카드로 정리해줘

그러면 영상 1개당 카드 1장씩 `docs/recipes/` 에 만들어집니다.
여러 개를 한꺼번에 넣어도 하나씩 다 정리됩니다.

---

## 자막이 안 받아질 때

| 증상 | 해결 |
|---|---|
| "로그인이 필요합니다" | `recipe.bat`이 자동으로 크롬 로그인 정보로 재시도합니다. **크롬을 완전히 종료**한 뒤 다시 실행하세요 |
| 자막 파일이 안 생김 | 그 영상에 자막이 아예 없는 경우입니다. 영상 아래 `⋯ 더보기 → 스크립트 표시`로 확인해보세요 |
| 한국어 자막이 아닌 게 받아짐 | 자동번역 자막만 있는 영상입니다. 그대로 정리는 가능하지만 정확도가 떨어집니다 |
| `node` 를 못 찾는다고 나옴 | [Node.js](https://nodejs.org) 20 이상을 설치하세요 |

자막이 아예 없는 영상은 **캡처 이미지를 채팅에 올려주셔도** 정리됩니다.

---

## 수동으로 하는 방법 (프로그램 없이)

영상 하나만 급하게 정리할 때는 이게 더 빠릅니다.

1. 유튜브 영상 아래 **`⋯ 더보기` → `스크립트 표시`**
2. 오른쪽에 나온 자막 전체를 드래그해서 복사
3. Claude 채팅에 붙여넣고 "레시피 카드로 정리해줘"

## 폴더 구조

```
docs/recipes/
├─ README.md          이 문서
├─ urls.txt           (선택) 한꺼번에 받을 주소 목록
├─ 자막/               받아온 자막 원본(.srt)과 정리본(.txt)
│   └─ _받은목록.txt    이미 받은 영상 기록 (중복 방지)
└─ {메뉴이름}.md        완성된 레시피 카드
```

> `.srt` 원본은 용량만 차지해서 git에 올리지 않습니다(`.gitignore`).
> 정리된 `.txt` 만 올라갑니다.
