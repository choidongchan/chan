# 피시방 메뉴 레시피 매뉴얼 (조리 표준서)

> **용도** — 카운터/주방 알바가 이 문서만 보고 바로 조리할 수 있게 만든 표준 레시피집입니다.
> 신입 교육용, 주방 벽 부착용, PLAYON 상품 등록용으로 그대로 쓸 수 있습니다.
>
> **레시피 기준** — 국내 피시방에서 실제로 통용되는 표준 조리법(라면조리기 + 전자레인지 + 에어프라이어/튀김기 구성)을 기준으로 정리했습니다.
> 매장 장비·납품 단가에 따라 물양/시간/원가는 **±10% 범위에서 매장 기준으로 한 번 보정**한 뒤 확정하세요.
> 보정한 값은 각 레시피의 `매장 확정값` 칸에 적어두면 그 뒤로는 그 숫자만 보면 됩니다.

## 1. 문서 사용법 & 표기 규칙

| 표기 | 의미 |
|---|---|
| ⏱ | 조리 시간 (주문 접수 → 좌석 서빙 완료까지) |
| 🔥 | 사용 장비 |
| 💰 | 원가 → 판매가 (예시값, 매장 보정 필요) |
| ⚠️ | 사고 나기 쉬운 지점 |
| 🍽 | 서빙 세팅 (그릇·수저·부재료) |

**계량 기준**

- 물 1컵 = 200ml, 종이컵 가득 = 180ml
- 라면 물 계량은 **눈대중 금지**. 조리기 눈금 또는 계량컵 고정 사용.
- "한 국자" = 국자 8부 능선 (≈ 90ml)
- 소스류 1펌프 = 15ml (펌프 통 사용 시)

**주문 접수 → 서빙 흐름 (PLAYON 기준)**

1. 좌석 PC/카운터에서 주문 접수 → `주문내역`에 기록
2. 조리 시작 시 **좌석번호 라벨을 트레이에 먼저 올린다** (오배달 1순위 원인)
3. 서빙 완료 → PLAYON `상품 판매` 처리 → 재고 자동 차감
4. 회수는 30분 뒤 순회 또는 손님 호출 시

## 2. 주방 장비 & 세팅

| 장비 | 표준 설정 | 비고 |
|---|---|---|
| 자동 라면조리기(3~6구) | 물 550ml / 3분 30초 | 구멍마다 물양 편차 확인 (첫 주 1회 계량컵 검증) |
| 온수기 | 92~96℃ 유지 | 컵라면·커피용. 아침 오픈 시 20분 예열 |
| 전자레인지 | 700W 기준 | 700W 아닌 기기면 시간 환산표(§3) 적용 |
| 에어프라이어 | 180℃ 기본 / 5분 예열 | 튀김기 없는 매장의 주력 장비 |
| 튀김기 | 175~180℃ 유지 | 기름 교체: 3~4일 또는 산가 체크 시 |
| 인덕션(보조) | 라볶이·볶음밥용 | 코팅 팬 전용, 금속 뒤집개 금지 |
| 냉동고 | -18℃ 이하 | 매일 온도 기록 |
| 냉장고 | 0~5℃ | 치즈·계란·반찬류 |

**주방 배치 원칙(동선)**

```
 [냉동고] → [전자레인지/에어프라이어] → [플레이팅대] → [트레이/서빙]
                     ↑
              [라면조리기 + 온수기]        ← 물·소스·부재료는 팔 뻗어 닿는 위치에
```

- 부재료(치즈·계란·떡·만두)는 **라면조리기 왼쪽 30cm 안**에 소분 통으로 상비
- 단무지·김치는 서빙 직전에 담는다 (미리 담아두면 물 생김)

## 3. 모든 메뉴 공통 규칙

### 3-1. 전자레인지 출력 환산표

| 700W 기준 | 1000W일 때 | 1200W일 때 |
|---|---|---|
| 1분 30초 | 1분 05초 | 55초 |
| 2분 | 1분 25초 | 1분 10초 |
| 3분 | 2분 05초 | 1분 45초 |
| 4분 | 2분 50초 | 2분 20초 |

### 3-2. 라면 물양 표 (가장 중요)

| 개수 | 물양 | 조리 시간 | 비고 |
|---|---|---|---|
| 1개 | 550ml | 3분 30초 | 기본값 |
| 2개 | 950ml | 4분 00초 | 1개×2가 아님. 물 100ml 줄임 |
| 3개 | 1,350ml | 4분 30초 | 3개부터는 두 구멍에 나눠 조리 권장 |
| 국물 많이 | +100ml | 동일 | 요청 시에만 |
| 꼬들면 | 동일 | -30초 | 면 넣는 타이밍만 뒤로 |
| 푹 익힘 | +50ml | +40초 | 불음 주의 |

### 3-3. 스프 투입 순서 (맛 차이가 실제로 남)

1. **물 먼저 끓인다** → 끓기 시작하면 **분말스프 → 건더기스프 → 면** 순서
2. 스프를 찬물에 미리 풀면 국물이 텁텁해진다 (⚠️ 신입이 가장 많이 하는 실수)
3. 면은 넣고 **30초 뒤 한 번만** 젓는다. 계속 저으면 면이 풀린다

### 3-4. 위생 규칙 (지키면 사고 안 남)

- 조리 전·후 손 세척, 생계란 만진 뒤 **반드시** 재세척
- 냉동식품 **재냉동 금지** (해동 후 남으면 폐기)
- 조리 도구 색 구분: 국물용 국자 / 소스용 국자 분리
- 유통기한 라벨: 개봉일 + 폐기일 매직으로 표기 (개봉 치즈 7일, 소분 소스 3일)
- 알레르기 고지 대상: **계란 / 우유(치즈) / 밀 / 대두 / 새우 / 돼지고기** — 문의 시 즉답 가능하게 메뉴판 하단 표기

### 3-5. 서빙 온도 기준

| 분류 | 서빙 온도 | 허용 대기 시간 |
|---|---|---|
| 라면·국물 | 70℃ 이상 | 조리 후 3분 이내 |
| 튀김류 | 65℃ 이상 | 5분 이내 (넘으면 눅눅) |
| 밥류 | 65℃ 이상 | 5분 이내 |
| 음료(냉) | 5℃ 이하 | 즉시 |

## 4. 라면류

> 피시방 매출의 40~50%가 여기서 나옵니다. **라면 하나만 제대로 잡아도 재방문율이 바뀝니다.**

### 4-1. 기본 라면 (시그니처)

- 🔥 라면조리기 / ⏱ 4분 / 💰 700원 → 3,500원 (마진 80%)

**재료**

| 재료 | 분량 |
|---|---|
| 봉지라면 | 1개 |
| 물 | 550ml |
| 대파(송송) | 1자밤 (≈5g) |
| 단무지 | 4~5쪽 (별도 접시) |

**조리 순서**

1. 조리기 물 550ml 세팅 → 끓임 (약 60초)
2. 끓으면 **분말스프 → 건더기스프** 투입, 5초 저어 녹임
3. 면 투입, 30초 뒤 젓가락으로 1회만 풀어줌
4. **3분 30초** 타이머 → 종료 30초 전 대파 투입
5. 그릇에 면을 먼저 집어 담고 → 국물을 부어 마무리 (면이 위로 봉긋하게)

🍽 라면그릇 + 앞접시(단무지) + 나무젓가락 + 냅킨 2장 + 좌석번호 라벨
⚠️ 서빙 지연 3분 넘어가면 면이 불어서 클레임 1순위. **조리 시작 = 서빙 준비 완료 상태여야 함**

`매장 확정값`: 물 ______ml / 시간 ______

---

### 4-2. 치즈라면

- 🔥 라면조리기 / ⏱ 4분 / 💰 950원 → 4,500원

1. 기본 라면과 동일하게 조리
2. **종료 20초 전** 슬라이스 치즈 1장을 면 위에 올린다 (국물에 담그지 않는다)
3. 그릇에 담을 때 치즈가 면 위에 얹힌 상태 유지 → 사진이 예쁘게 나옴

⚠️ 치즈를 처음부터 넣으면 다 녹아 국물이 걸쭉해지고 조리기 바닥에 눌어붙음
💡 치즈 2장 요청 시 +500원 (토핑 추가 단가는 §10 참고)

---

### 4-3. 계란라면

- 🔥 라면조리기 / ⏱ 4분 30초 / 💰 1,000원 → 4,000원

1. 기본 조리 진행
2. **종료 1분 30초 전** 계란 투입 — 세 가지 스타일을 손님에게 확인:
   - **풀어서**: 젓가락으로 저으며 붓기 → 국물이 뽀얘짐
   - **통으로(반숙)**: 한쪽에 살짝 깨 넣고 **절대 젓지 않음** → 종료 시 반숙
   - **완숙**: 종료 2분 30초 전 투입
3. 통계란은 그릇에 담을 때 **국자로 아래를 받쳐** 옮긴다 (터짐 방지)

⚠️ 계란은 조리기에 직접 깨지 말고 **작은 그릇에 깨서 확인 후** 투입 (껍질·상한 계란 사고 방지)

---

### 4-4. 떡라면

- 🔥 라면조리기 / ⏱ 5분 / 💰 1,000원 → 4,500원

1. 냉동 떡은 **미리 찬물에 5분 불려** 상비 (영업 전 준비)
2. 물이 끓으면 **스프 → 떡 먼저** 투입 (떡은 면보다 1분 먼저)
3. 1분 뒤 면 투입 → 3분 30초 조리
4. 떡이 바닥에 붙지 않게 면 투입 시 한 번 바닥을 긁어준다

⚠️ 불리지 않은 냉동 떡을 그냥 넣으면 → 겉만 익고 속은 딱딱. 클레임 확정
💡 떡 분량: 6~8개(약 60g). 더 넣으면 국물을 다 먹어버려 짜진다

---

### 4-5. 만두라면

- 🔥 라면조리기 / ⏱ 5분 / 💰 1,200원 → 4,500원

1. 냉동만두 4개는 **전자레인지 1분 선해동** (이게 핵심)
2. 물 600ml (만두가 물을 먹으므로 +50ml)
3. 스프 투입 → 만두 투입 → 30초 뒤 면 투입 → 3분 30초
4. 만두는 그릇 가장자리에 둘러 담아 플레이팅

⚠️ 선해동 없이 넣으면 만두피가 터져 국물이 탁해짐

---

### 4-6. 짜파구리

- 🔥 라면조리기 + 인덕션 / ⏱ 6분 / 💰 1,400원 → 5,500원

1. 물 600ml 끓임 → **면 2종(짜장면·우동면) 먼저** 투입, 4분 삶기
2. 종료 30초 전 **물을 8스푼(약 120ml)만 남기고** 따라 버림
3. 짜장 분말 + 우동 분말스프 절반 + 올리브유 1티스푼 → 30초 비빔
4. 검은 그릇에 담고 파슬리 또는 송송 대파 마무리

⚠️ 물을 너무 많이 남기면 소스가 묽어짐. **8스푼 규칙 고정**
💡 소고기·치즈 토핑 추가 판매 포인트

---

### 4-7. 불닭 계열 (볶음면)

- 🔥 라면조리기 / ⏱ 5분 / 💰 1,100원 → 4,500원

1. 물 600ml에 면만 **4분** 삶기 (스프 넣지 않음)
2. 물을 **거의 다 버리고** 4스푼(60ml)만 남김
3. 액상소스 전량 + 후레이크 → 30초 비빔
4. 치즈 추가 시: 비빈 뒤 치즈 1~2장 올려 **전자레인지 20초** → 녹여서 서빙

⚠️ 매운 소스는 눈·손 자극. 비빈 뒤 손 세척 필수
💡 "덜 맵게" 요청 → 소스 70%만 + 치즈 1장 기본 제공으로 표준화

---

### 4-8. 짬뽕라면 (업그레이드 메뉴)

- 🔥 라면조리기 / ⏱ 5분 / 💰 1,800원 → 6,000원

1. 냉동 해물믹스 40g을 전자레인지 1분 해동
2. 물 600ml 끓임 → 스프 → 해물 → 30초 뒤 면
3. 종료 30초 전 대파·양파 투입
4. 고운 고춧가루 1/2티스푼으로 색 보정 (선택)

⚠️ 해물은 **당일 사용분만** 해동. 재냉동 절대 금지 (식중독 위험 최상위)

---

### 4-9. 컵라면 (조리 없음)

- 🔥 온수기 / ⏱ 40초 / 💰 800원 → 1,500원

1. 뚜껑 절반 개봉 → 스프 투입 → **내부 표시선까지** 온수
2. 뚜껑 덮고 포크/젓가락으로 눌러 고정 → **3분 타이머와 함께 서빙**
3. 손님에게 "3분 뒤 드시면 됩니다" 한마디 = 컴플레인 예방

⚠️ 온수 온도가 낮으면(<90℃) 면이 안 익음. 오픈 시 온수기 예열 확인

## 5. 밥류 · 덮밥

### 5-1. 공깃밥

- 🔥 전자레인지 / ⏱ 2분 / 💰 500원 → 1,000원
- 즉석밥 700W **1분 30초**. 뚜껑을 살짝 열고 돌린다
- 라면 주문의 **약 40%가 공깃밥을 추가**한다 → 주문 시 반드시 권유

### 5-2. 김치볶음밥

- 🔥 인덕션 / ⏱ 6분 / 💰 1,500원 → 5,500원

| 재료 | 분량 |
|---|---|
| 밥 | 1공기(210g) |
| 김치(잘게 썬 것) | 80g |
| 스팸/햄 큐브 | 40g |
| 식용유 | 1큰술 |
| 고추장 | 1/2큰술 |
| 참기름 | 1/2티스푼 |
| 계란후라이 | 1개 |
| 김가루·깨 | 약간 |

1. 팬 예열(중강불) → 기름 → 햄 30초 볶기
2. 김치 투입 1분 볶기 → 고추장 넣고 30초 (여기서 김치 신맛이 날아감)
3. 밥 투입 → 눌러가며 2분 볶기 → 참기름 마무리
4. 밥그릇에 눌러 담아 접시에 엎어 **돔 모양**으로 플레이팅 → 계란후라이 올림 → 김가루·깨

💡 냉동 볶음밥 사용 매장: 전자레인지 700W 3분 → 계란후라이만 얹어도 완성도 급상승

### 5-3. 치킨마요덮밥

- 🔥 에어프라이어 + 전자레인지 / ⏱ 7분 / 💰 2,000원 → 6,000원

1. 냉동 치킨 6조각 → 에어프라이어 **180℃ 8분**
2. 공깃밥 데워 그릇에 담고 **간장소스 1큰술**을 밥에 먼저 두름
3. 치킨을 한 입 크기로 잘라 밥 위에 깔기
4. **마요네즈 지그재그 → 데리야키 소스 지그재그** 순서(반대로 하면 지저분해 보임)
5. 김가루 + 파슬리 + (선택) 반숙 계란

⚠️ 소스는 서빙 직전에. 미리 뿌리면 눅눅해짐

### 5-4. 제육덮밥

- 🔥 인덕션 / ⏱ 8분 / 💰 2,500원 → 7,000원

1. 양념 제육 150g(전처리 완제품 권장) 팬에 강불 3분 볶기
2. 양파 1/4개·대파 투입 1분
3. 밥 위에 얹고 참기름·깨 마무리, 상추 1장 곁들임

💡 피시방 주방 규모에선 **양념 완제품 납품**이 원가·시간·맛 편차 모두에서 유리

### 5-5. 라볶이

- 🔥 인덕션 / ⏱ 7분 / 💰 1,500원 → 5,500원

1. 물 400ml + 고추장 1큰술 + 고춧가루 1/2큰술 + 설탕 1큰술 + 간장 1/2큰술 끓임
2. 불린 떡 100g 투입 3분
3. 라면사리 투입 3분 → 어묵·대파 마무리
4. 국물이 **주걱 자국이 잠깐 남는 농도**가 되면 완성

⚠️ 소스는 미리 **1L 단위로 만들어 냉장 소분**(3일). 매번 계량하면 맛이 튀고 느리다

## 7. 토스트 · 간식

### 7-1. 햄치즈토스트

- 🔥 토스터/팬 / ⏱ 6분 / 💰 1,200원 → 4,000원

1. 팬에 버터 → 식빵 2장 노릇하게 (앞뒤 각 1분)
2. 계란 1개 스크램블 + 양배추채 30g 볶기 (소금 약간·설탕 1/2티스푼)
3. 빵 → 치즈 → 계란 → 햄 → **케첩+마요** → 빵
4. 반으로 잘라 유산지에 감싸 서빙 (손에 안 묻게 = 게임 중 손님 배려)

💡 **게임 중에 한 손으로 먹을 수 있는 형태**가 피시방 간식의 핵심 기준

### 7-2. 콘치즈

- 🔥 에어프라이어/전자레인지 / ⏱ 6분 / 💰 1,300원 → 4,500원

1. 옥수수 통조림 150g 체에 밭쳐 물기 완전 제거 (⚠️ 물기 남으면 질척해짐)
2. 마요네즈 2큰술 + 설탕 1/2큰술 + 후추 → 버무림
3. 그라탕 용기에 담고 모짜렐라 60g 덮기
4. 에어프라이어 **200℃ 6분** (치즈 갈색 점 생기면 완성) → 파슬리

### 7-3. 나초 치즈

- ⏱ 3분 / 💰 800원 → 3,000원
- 나초 60g + 체다 치즈소스 60ml(중탕 60℃ 유지) → 별컵 제공
- 치즈소스는 **중탕기에 상시 보온**. 식으면 굳어서 못 씀

### 7-4. 냉동피자

- 🔥 에어프라이어 / ⏱ 10분 / 💰 2,000원 → 6,000원
- 180℃ 9분. 유산지 깔고 조리 → 8등분 커팅 → 피클 곁들임

### 오픈 (영업 시작 30분 전)

1. 온수기 전원 ON (예열 20분)
2. 라면조리기 물 채움 + 전원 ON, 물양 눈금 확인
3. 튀김기 기름 상태·온도 확인(175℃)
4. 냉장/냉동고 온도 확인 및 기록
5. 부재료 소분 준비: 대파 / 치즈 / 계란 / 떡(찬물 불리기) / 단무지
6. 소스 통 보충, 일회용품 보충
7. 조리대·트레이 소독
8. PLAYON `상품관리`에서 **품절 항목 확인 → 판매 중지 처리**

### 마감

1. 라면조리기 물 배수 + 내부 세척
2. 튀김기 기름 여과 + 뚜껑 덮기
3. 에어프라이어 바스켓 세척(뜨거울 때 물 붓지 말 것 — 코팅 손상)
4. 슬러시 기계 세척
5. 남은 부재료 밀폐 후 냉장, 개봉일 라벨 갱신
6. 폐기 목록 기록 → PLAYON 재고 조정
7. 배수구·후드 청소, 쓰레기 배출
8. 재고 체크리스트(§12-1) 작성 → 발주

## 14. 자주 나는 사고 & 대처법

| 상황 | 원인 | 즉시 대처 | 재발 방지 |
|---|---|---|---|
| 면이 불어서 나감 | 조리 후 방치 | **재조리 후 사과** (그냥 내면 재방문 없음) | 조리 시작 전 서빙 동선 확보 |
| 국물이 짜다 | 물양 부족 | 뜨거운 물 추가 제공 | 계량컵 고정, 눈대중 금지 |
| 치즈가 바닥에 눌어붙음 | 투입 시점 이름 | 조리기 즉시 세척 | 종료 20초 전 규칙 준수 |
| 계란이 터짐 | 젓거나 급히 옮김 | 사과 후 스타일 재확인 | 국자로 받쳐 옮기기 |
| 튀김이 눅눅 | 예열 없음 / 방치 | 폐기 후 재조리 | 예열 5분, 5분 룰 |
| 오배달 | 좌석 라벨 누락 | 즉시 회수·재조리, 해당 좌석 사과 | 트레이 라벨 선(先)부착 |
| 손님이 음료를 키보드에 쏟음 | 뚜껑 미제공 | 전원 차단 → 장비 분리 → 건조 | 뚜껑·빨대 필수 제공 |
| 매운 소스 눈에 튐 | 세척 안 한 손 | 흐르는 물 15분 세척, 이상 시 병원 | 조리 후 손 세척 규칙 |
| 이물질 클레임 | 위생 관리 미흡 | **환불 + 즉시 사과 + 사진 기록** | 원인 추적, 도구 색 구분 |
| 알레르기 문의 | 표기 없음 | 원재료 그대로 고지 (추측 금지) | 메뉴판 알레르기 표기 |

**클레임 3단계 응대**

1. 반박하지 않고 먼저 사과 → 2. 재조리 or 환불 즉시 선택지 제시 → 3. PLAYON `시스템 로그`/메모에 기록

## 15. 신입 알바 3일 교육 커리큘럼

### 1일차 — 보고 익히기 (4시간)

- 주방 장비 위치·전원·안전 수칙
- 위생 규칙(§3-4) 숙지
- **기본 라면 10그릇 실습** (물양 계량 → 스프 순서 → 타이머 → 플레이팅)
- PLAYON: 주문 접수 → 상품 판매 처리 → 재고 차감 확인
- 목표: 기본 라면을 4분 안에 혼자 완성

### 2일차 — 응용 (4시간)

- 치즈·계란·떡·만두 라면 각 3회
- 공깃밥·볶음밥·덮밥
- 에어프라이어 튀김 3종
- 음료 제조 + 좌석 서빙 동선
- 목표: 동시 3주문 처리 (라면 + 튀김 + 음료)

### 3일차 — 실전 (피크타임 투입)

- 피크타임(저녁 7~10시) 선배 동행 근무
- 주문 우선순위 판단: **조리 시간이 긴 것부터 착수** (튀김 → 밥 → 라면 → 음료 순으로 시작, 완성은 동시에)
- 클레임 응대 롤플레잉
- 마감 루틴 전체 1회 수행
- 목표: 마감 체크리스트 단독 수행 가능

**숙련도 체크리스트**

- [ ] 라면 물양을 계량컵 없이도 눈금으로 정확히 맞춘다
- [ ] 동시 3주문을 완성 시점을 맞춰 낸다
- [ ] 재고 부족을 발견하면 스스로 발주 리스트에 적는다
- [ ] 클레임 상황에서 먼저 사과하고 선택지를 제시한다
- [ ] 마감 후 주방을 다음 오픈 상태로 만들어 둔다

## 부록 A. 피크타임 조리 우선순위

주문이 몰릴 때는 **접수 순서가 아니라 조리 시간 역순으로 착수**합니다.

```
접수: ①라면(4분) ②돈까스(13분) ③아이스티(1분) ④치킨마요(7분)

착수 순서:  ②돈까스 → ④치킨마요 → ①라면 → ③아이스티
완성 시점:  ────────────── 거의 동시에 ──────────────
```

- 시작 시각을 트레이 라벨에 적어두면 놓치지 않습니다
- 8분 넘는 메뉴가 3개 이상 밀리면 카운터에서 **예상 시간을 미리 고지**
